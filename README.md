# AlifeTactics: NPC combat behavior for STALKER Anomaly

AlifeTactics changes how NPCs fight in STALKER Anomaly. Every combat system reads the real state of the fight — the hit, the stats, the squad, the faction, the weapon, the range, the angle, the cover — and decides in the combatant's favor instead of by script or a die roll. It replaces no vanilla combat file, so it layers onto vanilla, GAMMA, and other combat-AI mods.

[ModDB](https://www.moddb.com/mods/stalker-anomaly/addons/alifetactics) | [Releases](https://github.com/damiansirbu-stalker/AlifeTactics/releases) | [Bugs, suggestions](https://github.com/damiansirbu-stalker/AlifeTactics/issues)

Requires: Anomaly 1.5.3, modded exes (themrdemonized or AOEngine), [xlibs](https://www.moddb.com/mods/stalker-anomaly/addons/xlibs-1001), MCM. Exact versions in [readme.txt](doc/readme.txt).
